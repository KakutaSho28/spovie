# 要件定義

## 1. 目的・背景

スポーツチームの練習・試合の振り返りでは、「映像のどこを、誰が、どう見ているか」がメンバー間でずれやすい。映像の上に直接描き込み（ペン・矢印・テキスト）、見てほしい区間をループ再生し、コメントとともに共有できるようにして、チームの「見る目」を揃える。

## 2. 対象ユーザー

| ユーザー | 想定する使い方 |
|---|---|
| コーチ・分析担当 | 試合映像の重要場面に描き込み、区間とコメントを付けて共有する |
| 選手 | 共有された場面を見て、コメントで質問・感想を返す |
| チーム外の人 | 共有リンクだけで、ログインせずに場面を見る |

## 3. 機能要件

優先度: 必須 = v1 に含む。

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F01 | ユーザー認証 | 登録・ログイン・ログアウト（Bearer トークン） | 必須 |
| F02 | YouTube 動画の登録 | URL（watch?v= / youtu.be / embed）から登録。一覧・詳細・削除 | 必須 |
| F03 | 動画のアップロード | mp4 を最大 200MB まで。保存先は S3 互換ストレージ | 必須 |
| F04 | アノテーション作成 | ペン・矢印・テキスト、元に戻す、選択削除、色の選択 | 必須 |
| F05 | ループ区間 | 開始〜終了秒を指定してループ再生（YouTube / mp4 両対応） | 必須 |
| F06 | アノテーション保存・一覧・削除 | 区間・描画・コメントを保存。**画面サイズが違っても同じ相対位置で再現** | 必須 |
| F07 | 共有リンク | 有効期限つき。ログイン不要で閲覧（YouTube / アップロード動画） | 必須 |
| F08 | 切り抜き | アップロード動画のみ。非同期処理、推測できないダウンロード URL、LINE 共有 | 必須 |
| F17 | チーム | 作成、招待 URL で参加、メンバー削除・脱退、チーム動画の共有 | 必須 |
| F18 | コメント + リアルタイム | アノテーションごとのスレッド。追加・削除・新規アノテーションを開いている全員へ即時反映 | 必須 |
| F19 | PWA | ホーム画面に追加、オフラインでもアプリが起動、表示済み一覧のキャッシュ | 必須 |
| F20 | 動画一覧のページ送り | 1 ページ 20 件 | 必須 |
| F21 | 公開デモ | デモアカウントとシードデータ | 必須 |

## 4. 非機能要件

| 区分 | 要件 | 実現方法 |
|---|---|---|
| セキュリティ | 他人・他チームのデータにアクセスできない | Policy（個人動画は投稿者のみ、チーム動画はメンバー）、WebSocket チャンネルも同じ権限で認可 |
| セキュリティ | クリップのダウンロード URL を推測できない | 40 文字のランダムトークン |
| セキュリティ | CORS は許可したオリジンのみ | `CORS_ALLOWED_ORIGINS`（ワイルドカード不可） |
| 著作権 | YouTube 動画の映像データを保存しない | 座標データのみ保存。切り抜きは YouTube 動画に対して 422 |
| 性能 | 大きい動画アップロードでプロキシがタイムアウトしない | 上限 200MB。再生・DL は署名付き URL でストレージから直接配信 |
| 可用性 | 稼働を監視できる | `GET /api/health`（DB 接続確認） |
| 保守性 | API 仕様が実装とずれない | 仕様書をコードから自動生成し、CI でずれを検知 |
| 保守性 | 層の責務が明確 | FormRequest → Policy → Controller → Service → Resource |
| 互換性 | 画面サイズ・端末が違っても描画が同じ位置に出る | 保存時のキャンバスサイズとの比率で復元 |
| オフライン | ネットワークが無くてもアプリが起動する | Service Worker（アプリシェルのプリキャッシュ）。接続が必要な操作は UI で明示 |

## 5. スコープ外（v1 では作らない）

AI による選手トラッキング、コートマップの自動生成、外部動画サービス連携、YouTube 以外の動画配信サービス、他競技への特化機能、課金、ネイティブアプリ。

## 6. 著作権ポリシー（変更しない）

- **YouTube 動画**: アノテーション（座標データ）と共有リンクのみ。切り抜き・動画データの保存・ダウンロードは行わない。
- **アップロード動画**: 利用者が権利を持つ動画のみ想定。切り抜きとダウンロードが可能。
- 公開デモのシードデータは YouTube 動画のみ（Blender Foundation 公式の CC BY 短編映画）。著作権のあるファイルはアップロードしない。
- 端末へのキャッシュ（PWA）でも、動画ファイルとクリップは保存しない。

## 7. 前提・制約

- バックエンドは Laravel 10 / PHP 8.2、フロントエンドは React + TypeScript、デプロイは Railway（API・worker・MySQL）と Vercel（SPA）。
- Laravel 10 系は修正版が提供されない既知の脆弱性が 4 件あり（`composer audit`）、`APP_DEBUG=false` で運用する。恒久対応は Laravel 12 以降への更新。
